Inputs — what gets summed into the stream

Three id arrays, three tables, one sum. The decoder has no segment table — its objective never needed one.

Projections — Q, K, V and the 12×64 view

One learned 768→768 (or fused 768→2304) projection, then a zero-math view: head h owns dims 64h…64h+63 of every token.

Attention — same machinery, one line of difference

Rows = query (looking), columns = key (looked at); each row sums to 1. The decoder inserts −∞ above the diagonal before softmax — the leak argument made visible.

The layer — tokens talk, tokens think

Attention moves information between tokens; the FFN transforms each token alone (768→3072→768, two-thirds of the layer's parameters). The order of LayerNorm differs: BERT normalizes after each add (post-LN), GPT-2 normalizes before each sublayer (pre-LN).

Native task — fill the blank vs continue the text

Same size, same machinery. What differs is the interface the pretraining objective gave each model: the encoder repairs, the decoder continues.
